Cathedrals Opening Bazaars: Firms’ Open-Source Projects and Community Participation

求职主论文。龚啸峰，独著。2026 年 11 月 6 日版本。

阅读论文（PDF，英文，99 页） 仅正文（34 页） 在线附录（69 页）

研究问题

申请专利的大型企业也在 GitHub 上发布开源代码，任何人都可以阅读、使用并在其基础上继续开发，拥有账户的人都可以报告问题或提出修改。企业层面的总量无法显示，与企业专利技术重叠的项目是否有更多人参与。这一比较必须逐个项目进行，并把代码和专利放进同一个分类体系；而数据中的两道缺口让二者无法对接：开源代码没有专利分类，企业数据库也不列出 GitHub 账户。

企业在其申请专利的技术领域发布代码时，谁会参与？新参与者又为企业的项目贡献了多少？

核心比较

位于企业近期获得专利授权的技术领域内的代码仓库，在首个活跃季度之后的 24 个月内，新参与者多 29.5%，新参与者的贡献多 45.5%。所有人的贡献也更多，而新参与者在贡献中所占的份额没有明显差异。这些是相关关系，估计结果并未说明原因。

摘要（英文原文）

This paper studies how participation in firms’ open-source projects relates to the technologies the firms patent. I link Compustat firms to their USPTO patents and GitHub accounts and use a large language model to place each project in the Cooperative Patent Classification, the scheme patent examiners use. I document that most of these projects lie in technologies in which the firm was recently granted patents. I then compare projects first active in 2015–2022, conditional on firm-by-year and technology-by-year effects and on controls for each project’s early activity, text and language. I find that projects in the firm’s patented technologies have more new participants and more contributions from them. The difference in new participants holds for people with no earlier activity on the firm’s GitHub accounts and without the five largest firms. Contributions from everyone are also higher, and among projects with a contribution there is no clear difference in new participants’ share. According to my estimates, projects in the firm’s patented technologies have 29.5 percent more new participants in the 24 months after their first active quarter, 45.5 percent more contributions from them, and 37.6 percent more contributions from everyone.

数据与方法

  • 连接企业。匹配表把 Compustat 企业连接到其 USPTO 专利和 GitHub 账户，每条连接都记录其依据以及企业拥有该账户的年份。专利匹配表覆盖了 DISCERN 连接到美国总部企业的 2015–2021 年专利中的 99.7%。
  • 为代码分类。大语言模型阅读每个仓库的名称、描述、主题标签、编程语言和 README，并为其分配合作专利分类（CPC，专利审查员使用的分类体系）中的大组。在双方都能分类的仓库中，76.4% 的仓库，其标签与欧洲专利局文本分类工具的标签至少有一个相同的大组；若在同一 CPC 部内随机分配标签，这一比例为 38.5%。
  • 专利领域内。若仓库至少一半的标签权重落在其企业在截至首次活动当年的五个授权年度内获得专利的大组中，即称其位于专利领域内。在 2015–2022 年首次活跃的 102,987 个仓库中，79.7% 位于领域内，因此比较对象是领域外的少数仓库。
  • 参与。贡献指 GH Archive 所记录的 GitHub 公开事件中的议题（issue）、拉取请求（pull request）、评审或评论，不计机器人账户。新参与者是指在仓库首个活跃季度结束前没有任何活动、并在随后八个季度内首次作出贡献的人。
  • 估计。采用泊松伪最大似然估计（PPML），控制企业×年份效应、大组×年份效应，以及每个仓库在创立季度的活动、文本和编程语言。标准误按企业聚类，p 值按 Holm 方法对共同检验的结果进行调整。

主要发现

  • 新参与者更多。专利领域内的仓库在头两年中的新参与者比其他仓库多 29.5%（95% 置信区间 14.6 至 46.4）。
  • 两类人的贡献都更多。新参与者的贡献高 45.5%，所有人的贡献高 37.6%。在有贡献的仓库中，新参与者占贡献的份额在领域内高 1.02 个百分点（95% 置信区间 −0.52 至 2.55），因此估计结果不能说明新参与者占有更大的份额。
  • 企业的新面孔。对于此前在该企业 GitHub 上没有任何活动的新参与者，差异为 27.6%。去掉五家最大的企业后，新参与者及其贡献的估计分别为 28.1% 和 40.1%。
  • 已有观点。正的差异与“与专利相关的代码参与较少”的预测相反。关于差异应在何处更大的五个对比是在看到结果之前设定的，它们都没有为相应预测提供统计上明确的支持。

结果的边界

  • 这些是条件相关关系。项目的重要性、受众和企业支持仍是可能的解释，估计结果并未说明原因。
  • “专利领域内”记录的是共享的技术类别，而不是某项专利是否覆盖仓库的代码；专利授权也可能晚于仓库的首次活动。
  • 该比较有一部分是在不同企业的仓库之间进行的。
  • 阅读、下载和运行代码不会在记录中留下痕迹，因此数据无法区分领域内仓库是用户更多，还是用户中留下工作的比例更高。
  • 模型读取的是各仓库在 2026 年的文本，晚于所有结果窗口。
  • 参与者按其此前在 GitHub 上的活动来描述，没有人与雇主相匹配。
